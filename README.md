# Hello Eightfold

A minimal Eightfold adaptation that proves the Treasury install and
execution flow end-to-end.

## Behavior

The `eightfoldHello` tool takes a name and returns a greeting.

Input:

```json
{ "name": "Dino" }
```

Output:

```text
Hello Dino from Eightfold.
```
